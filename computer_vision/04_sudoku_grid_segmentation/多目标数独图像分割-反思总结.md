# 多目标数独图像分割反思总结（拓展版）

本次在单目标数独分割程序的基础上，实现了对 `sudoku2.png` 中多个数独题目的自动检测和逐个处理。运行后程序会自动统计检测数量，并在输出目录保存检测总览图、每个题目的透视矫正图、9×9 网格可视化图和数字单元格分割图。

主要修改如下：

1. 原程序只对轮廓按面积排序后取第一个最大轮廓。新程序保留所有面积足够大的外部轮廓，并逐个作为候选区域处理，因此能从单目标流程扩展到多目标流程。
2. 为减少非数独区域带来的干扰，候选区域经过了面积阈值、近似四边形（或最小外接矩形）、宽高比和凸包填充率筛选。宽高比允许一定范围，是为了兼容拍摄角度造成的透视变形。
3. 对每一个通过筛选的候选区域，均独立执行四角点排序、透视变换、9×9 等分和数字提取。这些操作封装成函数，主程序用循环处理所有数独目标。
4. 输出文件使用 `sudoku_01_corrected.png`、`sudoku_01_grid.png`、`sudoku_01_digits.png` 等不同名称，避免多题结果互相覆盖；另外保存 `00_detection_overview.png`，可直观看到原图中每一个检测框与编号。
5. 数字提取时不再依赖弹窗查看，而是裁掉每个小格周边的一圈区域以抑制网格线，再以连通域面积、宽高条件过滤噪声，最后将数字居中缩放到统一大小。

本次实验让我认识到，单目标图像处理与多目标图像处理的关键区别不只是把“最大轮廓”改成循环，而是还要设计候选区域筛选、稳定编号和结果管理。自适应阈值窗口大小、闭运算核大小、候选最小面积比例、四边形近似精度和数字最小连通域面积都会影响稳定性。若个别图片分割效果不理想，可以优先围绕这些参数调节。
