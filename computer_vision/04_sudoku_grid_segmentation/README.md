# 04 - 数独题目图像分割与多目标透视矫正

## 项目简介
本项目针对手拍纸质数独照片（包含视角倾斜、纸张弯曲、阴影、同一视野内存在多个数独题目等复杂情况），构建了一套全自动的计算机视觉图像分割流水线。能够精准检测画面中的单目标或多目标数独题目区域，执行四点透视变换校正，并将 81 个数字网格单元进行切片分割，为下游 OCR 数字识别提供标准正向的切片输入。

---

## 核心算法流程
1. **图像自适应预处理**：
   - 灰度化转换；
   - 高斯滤波降噪消除印刷纸纹；
   - 自适应阈值化（`cv2.adaptiveThreshold`），在不均匀光照下依然保留清晰边框。
2. **多目标轮廓提取与几何拓扑筛选**：
   - 使用 `cv2.findContours` 提取画面所有外轮廓；
   - 根据多边形逼近（`cv2.approxPolyDP`）、凸包检测、长宽比（Aspect Ratio 近似 1:1）、面积占幅等几何特征准确定位数独外边框；
   - 支持同一画面内多个并排数独题目的独立检出。
3. **四点透视变换与正投影**：
   - 提取四个角点（左上、右上、右下、左下）；
   - 构建仿射/透视变换矩阵，将倾斜梯形校正为正方形标准图（500x500 像素）。
4. **81 宫格网格分割与数字区域提取**：
   - 沿水平与垂直轴均分成 9x9=81 个候选小网格；
   - 边距剔除与形态学开闭运算消除网格线干扰，纯化内部印刷体数字区域。
