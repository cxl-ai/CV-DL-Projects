# 02 - 自动驾驶车道线检测与曲率多项式拟合

## 项目简介
本项目针对车载前视相机采集的高速公路与复杂道路视频，构建了一套高鲁棒性的经典车道线检测流水线。通过逆透视变换（IPM）消除近大远小的透视失真，并利用滑动窗口（Sliding Windows）与二次多项式拟合精准提取车道线方程，实时计算车道曲率半径与车辆偏离车道中心的偏移量。

---

## 核心处理流水线
1. **图像预处理**：灰度化、高斯平滑降噪、色彩空间转换（RGB/HLS/LAB），提取黄色与白色车道线特征。
2. **边缘与梯度检测**：结合 Sobel 算子在 X 方向的梯度与 Canny 边缘检测，输出高质量的二值化边缘图。
3. **透视变换（IPM 俯视鸟瞰图）**：选取梯形感兴趣区域（ROI），通过 4 点单应性变换映射为平行俯视图。
4. **直方图峰值寻峰与滑动窗口搜索**：
   - 沿垂直方向累加像素直方图，确定左右两条车道线的起始基点；
   - 采用多层滑动窗口沿纵向追踪点云，动态自适应调整窗口中心。
5. **二次多项式拟合与曲率解算**：
   - 使用 NumPy 对提取的像素点拟合二次曲线：$x = Ay^2 + By + C$；
   - 结合现实空间米制比例系数，计算真实物理世界下的曲率半径与中心偏移量。
6. **逆投影与可视化绘制**：将车道多边形绿色区域逆投影回原相机视角，并合成行驶参数 HUD。
